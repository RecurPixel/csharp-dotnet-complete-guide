### **DO:**

- Everything builds on basics

## Book Conventions

### **Symbols Used:**

✅ **Completed** - Mark problems you've finished
⭐ **Difficulty** - Problem difficulty rating (⭐ to ⭐⭐⭐⭐⭐)
💡 **Tip** - Important insights
🚨 **Warning** - Common mistakes to avoid
🎯 **Goal** - Learning objective
📝 **Bonus** - Optional challenge
🔥 **Interview** - Likely interview question

### **Code Formatting:**

**Inline code:** `var x = 5;`

**Code blocks:**
```csharp
// This is C# code
public class Example
{
    public void Method()
    {
        Console.WriteLine("Hello, World!");
    }
}
```

**Output:**
```
Hello, World!
```

### **Problem Format:**

Each problem follows this structure:
1. **Problem Statement** - What to build
2. **Concepts** - What you'll learn
3. **Instructions** - Step-by-step guide
4. **Bonus** - Optional challenges
5. **Solution** - Full implementation (foundation problems)
   or Guidance only (interview problems)
