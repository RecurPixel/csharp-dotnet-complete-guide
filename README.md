# C# & ASP.NET Core Complete Learning Suite

Welcome to a comprehensive three-part learning resource for C# and ASP.NET Core development!

## 📚 Three Complete Books

This suite contains three integrated books designed to take you from C# fundamentals to building enterprise applications with ASP.NET Core.

### 1. **C# Fundamentals** 
A progressive guide covering core C# language features, from basic data types to advanced concurrency patterns.
- Covers essential language features and concepts
- Progressive difficulty from beginner to intermediate
- [Start C# Book →](csharp/)

### 2. **ASP.NET Core Development**
Complete guide to building modern web applications with ASP.NET Core framework.
- Project structure and configuration
- Routing, controllers, and middleware
- Authentication, authorization, and security
- Testing and error handling
- [Start ASP.NET Core Book →](aspnetcore/)

### 3. **Complete Workbook**
Hands-on practicum with exercises, interview preparation tracks, and structured learning phases.
- Setup guides and quick reference materials
- Interview preparation tracks
- Phased learning progression
- Troubleshooting guides
- [Start Workbook →](workbook/)

## 🚀 How to Use This Suite

1. **Beginners**: Start with the C# Fundamentals book to build a solid foundation
2. **Intermediate**: Move to ASP.NET Core Development for web application skills
3. **Practice**: Use the Complete Workbook for hands-on exercises and real-world scenarios

Use the sidebar to navigate through all three books seamlessly. Each book is organized by topic with clear progression.
